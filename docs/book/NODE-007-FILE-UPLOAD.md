# NODE 007 — FILE UPLOAD

**Status:** Built, deployed, proven in the browser
**Type:** `block.file_upload` · **Family:** Face (what the customer touches)

## Why it is node seven

The machine's only sense was typed words. A dentist could not hand it a price
list; a customer could not show it a photo of the broken part.

And here is the embarrassing truth this node repairs: the customer page had
carried an upload field **for months** — storing only the file's **name**. The
engine heard *"the customer attached menu.pdf"* while the menu itself never
left the browser. Furniture, dressed as a feature.

## The six answers

**1. Called:** File Upload
**2. Does:** Lets your customer hand the agent a file — documents become
words, pictures reach the Brain's eyes.
**3. Needs:** nothing — the customer supplies it
**4. Gives:** `file` — the file's name and its words
**5. Settings:** *Hint text* · *Must attach?* — kinds and size belong to the
**admin**, never asked of the architect
**6. Proof:** handed the live page a real `invoice.txt` reading "the total
owed is 417 pounds, due Friday", asked *"how much is owed, and by when?"* —
the agent answered **"417 pounds, due Friday."** The machine read a document
for the first time.

## The three kinds, honestly

**Documents** (PDF, Word, text, CSV) are read into words by the same machinery
Memory already trusts.

**Pictures** ride whole to the Brain's own eyes — the provider plumbing always
existed. One honest note: seeing needs a vision model, and until OpenAI,
Claude or Gemini billing is live, the only paid brain has no eyes. The moment
one is paid, photos work with zero code changes.

**Video is refused at the door, in one sentence** — *"Videos can't be read
yet."* No model here can watch one. A refusal that explains itself beats a
file silently swallowed.

## The admin's half

Nodes → File Upload → Limits: pictures on/off, and the size dial — which is
Memory's own 5 MB dial shown as a pointer, because one fact lives in one home.

## The line that matters

> **A sense that only records the name of what it was shown is not a sense.
> Now the machine can be handed things.**
